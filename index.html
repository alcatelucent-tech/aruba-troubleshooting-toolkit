Aruba Wireless Troubleshooting Toolkit

Platform-implementation reference for engineers managing Aruba OS 8 & Aruba Central OS 10.

Aruba Instant (IAP)

Virtual Controller (VC) terdistribusi. Forwarding dilakukan secara lokal (bridge) tanpa dependensi controller fisik terpusat.

ArubaOS 8 Campus

Mobility Conductor (MCR) & Controller (MC). Traffic klien di-tunneling lewat GRE (IP 47) ke firewall PEF terpusat.

Aruba Central (AOS 10)

Cloud-native control plane microservices. Mengeliminasi Conductor lokal dengan dukungan Bridge Mode dan Gateway Microbranch.

DHCP Option 43 & 60 Generator

Hasilkan sintaks otomatis untuk server DHCP Cisco, Windows Server, Dnsmasq, dan Mikrotik.

Tujuan & Fungsi Provisioning Wajib (L3 Discovery)

Memberikan informasi alamat IP Mobility Controller / Conductor kepada Access Point yang berada di subnet VLAN yang berbeda dari controller (melewati router L3). Tanpa Option 43 atau DNS, AP tidak akan bisa menemukan controller dan stuck di mode unprovisioned.

• Rekomendasi TAC: Gunakan IP VRRP (Virtual IP Controller Cluster) sebagai target Option 43 agar AP tetap bisa join jika salah satu controller mati.
• Kemungkinan Kegagalan: Format Hex di Windows DHCP salah ketik akan menyebabkan AP mencoba connect ke IP 0.0.0.0 atau loop reboot.

PoE Power Budget Calculator & IPM Behavior

        
Uji kompatibilitas alokasi daya switch (802.3af/at/bt) terhadap operasional radio AP Indoor & Outdoor Wi-Fi 6 & 6E.

      


      
      

        

          Tujuan & Fungsi Hardware Power
          Kritis (Layer 1 Foundation)
        

        

          Memastikan port PoE switch access mampu mencukupi daya maksimum AP. Jika daya kurang dari spesifikasi, fitur IPM (Intelligent Power Monitoring) Aruba akan mematikan radio frekuensi tertentu secara sepihak untuk mencegah AP mati total.
        

        

          
• Rekomendasi TAC: Aktifkan protokol LLDP di switch port agar AP bisa bernegosiasi alokasi daya PoE+ secara dinamis.

          
• Risiko Lapangan: AP outdoor (AP-575/AP-585) yang dipasang heater/antena eksternal wajib menggunakan injektor PoE 802.3bt (60W). Jika hanya 802.3at, AP akan boot loop saat suhu dingin.

802.11 Deauth & Disassociation Reason Code Decoder

        
Terjemahkan kode angka pemutusan frame (IEEE 802.11 Table 9-45) ke akar masalah teknis.

      


      
      

        

          Tujuan & Fungsi Frame Analysis
          Wajib untuk Tiket Client Drop
        

        

          Saat klien mendadak terputus dari Wi-Fi, frame 802.11 Deauthentication selalu menyertakan kode alasan (*Reason Code* angka). Tool ini menerjemahkan angka tersebut untuk memastikan apakah klien terputus karena roaming normal, salah password PSK, atau ditendang oleh controller karena session timeout.
        

      


      

        

          
          

            
            
Ketik angka kode alasan pemutusan koneksi yang muncul di log.

          

        


        

          

          

          

        

        

          Ketikkan angka reason code di atas (misal: 2, 4, 8, 15, atau 23).

MAC vendor (OUI) lookup

        

        
identify a device manufacturer from a MAC address — real IEEE registry data

      


      
      

        

          Tujuan & Fungsi Device Profiling
          Wajib untuk Rogue & Audit
        

        

          Mengidentifikasi pabrikan perangkat yang terhubung ke jaringan hanya dari 6 karakter pertama MAC address (OUI). Sangat berguna saat menemukan IP asing di firewall atau mendeteksi Rogue AP tak dikenal.
        

        

          
• Private MAC Trap: Jika bit ke-2 bernilai 2, 6, A, atau E (contoh: DA:..., FE:...), perangkat mengaktifkan mode Private/Randomized MAC bawaan iOS/Android sehingga nama pabrikan aslinya disembunyikan.

          
• Database Offline: Dilengkapi dengan database offline IEEE resmi ribuan vendor (Apple, ZTE, Cisco, Aruba, Samsung, Huawei, Intel, dll) tanpa ketergantungan koneksi internet luar.

Aruba Wireless Troubleshooting Toolkit

Platform-implementation reference for engineers managing Aruba OS 8 & Aruba Central OS 10.

Aruba Instant (IAP)

Virtual Controller (VC) terdistribusi. Forwarding dilakukan secara lokal (bridge) tanpa dependensi controller fisik terpusat.

ArubaOS 8 Campus

Mobility Conductor (MCR) & Controller (MC). Traffic klien di-tunneling lewat GRE (IP 47) ke firewall PEF terpusat.

Aruba Central (AOS 10)

Cloud-native control plane microservices. Mengeliminasi Conductor lokal dengan dukungan Bridge Mode dan Gateway Microbranch.

802.11 Deauth & Disassociation Reason Code Decoder

        
Terjemahkan kode angka pemutusan frame (IEEE 802.11 Table 9-45) ke akar masalah teknis.

      


      

        

          
          

            
            
Contoh umum: 2 (Prev Auth Expired), 4 (Inactivity), 8 (STA Leaving), 15 (4-Way Timeout), 23 (802.1X Failed)

          

        


        

          
Reason Code 2: Previous authentication no longer valid

          
Client atau AP mengakhiri sesi karena autentikasi sebelumnya sudah kedaluwarsa atau state mesin direset.

          
Tindakan: Periksa sesi session-timeout di user-role, roaming failure, atau client berpindah AP tanpa FT (802.11r).

MAC vendor (OUI) lookup

        

        
identify a device manufacturer from a MAC address — real IEEE registry data

      


      
      

        Paste a MAC address or just its first three octets (the OUI). This fetches and caches Wireshark's own mirror of the IEEE OUI registry — the same data a packet-capture tool like the Beacon Finder resolves vendors from, just as a quick standalone lookup when you don't have a full capture, e.g. for identifying a rogue AP or unrecognized client fast from its BSSID alone.
      


      
      

        
        

          
          
        

      


      
Matched from the IEEE OUI registry (via Wireshark's mirror).


      
      

        
VENDOR

        
Apple, Inc.

        

      


      
      

        
Data freshness

        

          • documented — the source file explicitly asks consumers "please don't download it more often than [weekly]," since it's regenerated on that cadence from IEEE's own registry. This tool respects that: the OUI list is fetched once and cached in this browser's local storage for 7 days before refetching, not re-fetched on every lookup.
        

      


      
      

        
Sources

        
wireshark.org/download/automated/data/manuf — Wireshark's maintained mirror of the IEEE OUI registry (CORS-enabled; the canonical IEEE CSV at standards-oui.ieee.org is real but has no CORS header, so it can't be fetched directly from a browser)

        
standards-oui.ieee.org — the registry this data is ultimately sourced from

    • 
          
  • PSC (Preferred Scanning Channels): Client 6 GHz hanya men-scan kanal kelipatan 16 (ch 5, 21, 37, 53...).

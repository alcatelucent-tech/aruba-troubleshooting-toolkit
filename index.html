Aruba Wireless Troubleshooting Toolkit

Platform-implementation reference for engineers managing Aruba OS 8 & Aruba Central OS 10.

Aruba Instant (IAP)

Virtual Controller (VC) terdistribusi. Forwarding dilakukan secara lokal (bridge) tanpa dependensi controller fisik terpusat.

ArubaOS 8 Campus

Mobility Conductor (MCR) & Controller (MC). Traffic klien di-tunneling lewat GRE (IP 47) ke firewall PEF terpusat.

Aruba Central (AOS 10)

Cloud-native control plane microservices. Mengeliminasi Conductor lokal dengan dukungan Bridge Mode dan Microbranch IPsec Gateway.

Status Key & Confidence Levels

Semua command dan panduan di toolkit ini divalidasi langsung dari dokumen TAC Aruba, User Guide AOS 8.10/8.12, dan implementasi live AOS 10.

AP Discovery & CPsec Whitelist (ArubaOS 8)

        
Urutan protokol pencarian controller dan enkripsi control-plane IPsec.

      


      

        

          
1. Urutan Discovery Controller (Discovery Hierarchy)

          
    
            
  1. Static NVRAM Variable: AP mengecek variabel master=<IP> di environment bootloader.
    2. 
            
  2. DHCP Option 43: Vendor specific string berformat IP string atau hex pasangan IP Controller.
    3. 
            
  3. ADP (Aruba Discovery Protocol):
              
      
                
    • Multicast: Frame ke IP 239.0.82.11.
      • 
                
    • Broadcast: Paket UDP ke port UDP 8211.
      • 
              
    
            
    4. 
            
  4. DNS Resolution: Resolve query default: aruba-master.<domain>.
    5.

ClientMatch & Roaming Optimization (802.11k/v/r)

        
Mengatasi fenomena sticky client dan verifikasi steering radio.

      


      

        

          
1. Protokol Roaming Assist: 802.11k, 802.11v, 802.11r

          
    
            
  • 802.11k (Neighbor Reports): AP memberikan daftar AP tetangga terbaik sehingga client tidak perlu scan seluruh kanal saat roaming.
    • 
            
  • 802.11v (BSS Transition Mgmt): AP memerintahkan client berpindah ke BSSID lain yang memiliki SNR lebih tinggi melalui frame disassociation imminent.
    • 
            
  • 802.11r (Fast BSS Transition): Mengeliminasi handshake 802.1X penuh saat roaming antar AP dalam cluster yang sama (kritis untuk Voice/VoIP).
    • 
          

        


        

          
2. Debugging ClientMatch di Controller

          

            
# Cek riwayat steering untuk MAC client tertentu:

            
(MC-01) # show ap client-match-history client-mac <mac>

            
# Cek status kalkulasi AirMatch radio:

            
(MCR) # show airmatch report ap-name <AP-Name>

AP Conversion Playbook (IAP • CAP • AOS 10)

        
Panduan langkah konversi mode operasional antar arsitektur.

      

      

        

          
1. IAP → Campus AP (AOS 8 MC)

          
Eksekusi via CLI Virtual Controller:

          
IAP# convert-aos-ap cap <IP-Controller>

          
AP me-reboot dan menarik firmware image dari Mobility Controller.

        

        

          
2. Campus AP → IAP Standalone

          
Eksekusi melalui console bootloader:

          

            apboot> purgeenv

            apboot> clear os

            apboot> saveenv

            apboot> reset
          

        

        

          
3. IAP / CAP → Aruba Central AOS 10

          
Assign Foundation License di GreenLake & masukkan ke Group AOS 10. AP otomatis upgrade via Activate.

        

        

          
4. Central AOS 10 Rollback → AOS 8

          
Unassign lisensi di GreenLake, keluarkan AP dari Group, lalu downgrade image firmware via console.

        

      

    


    
    

      

        
Bridge Mode vs Microbranch (AOS 10)

        
Pemilihan mode forwarding pada deployment cloud tanpa controller lokal.

      


      

        

          
Bridge Mode (Local Switched)

          

            Traffic klien langsung di-bridge ke port switch access VLAN lokal. Tidak memerlukan Gateway fisik di kantor cabang.
          

          
    
            
  • Cocok untuk Campus, Retail, dan Warehouse.
    • 
            
  • DHCP ditangani oleh router/switch core lokal.
    • 
            
  • Policy firewall PEF dieksekusi langsung di CPU AP.
    • 
          

        

        

          
Microbranch (IPsec VPN to Gateway)

          

            AP membentuk tunnel IPsec terenkripsi langsung ke Aruba VPNC / Campus Gateway di Datacenter.
          

          
    
            
  • Cocok untuk Work-From-Home (Teleworker) & Kios perbankan.
    • 
            
  • Mendukung Split-Tunneling (traffic korporat ke VPN, traffic internet lokal langsung keluar).
    • 
            
  • AP menyediakan DHCP lokal untuk perangkat rumahan.
    • 
          

        

      

    


    
    

      

        
Auth-tracebuf Live Decoding (802.1X & ClearPass)

        
Perintah tercepat mengisolasi titik putus handshake EAP/RADIUS di controller.

      

      

        (MC-01) # show auth-tracebuf mac 48:2a:e3:11:22:33
      

      

        

          
server-timeout

          
RADIUS Server mati, port UDP 1812 diblokir, atau Shared Secret mismatch.

        

        

          
eap-failure

          
Password salah, akun AD locked, atau policy service di ClearPass tidak match.

        

        

          
client-timeout

          
Supplicant client menolak trust sertifikat EAP ClearPass (isu CA certificate).

        

      

    


    
    

      

        
RFC 3576 CoA & Dynamic Authorization (UDP 3799 vs 5999)

        
Mengatasi kegagalan Change of Authorization dan Disconnect Message dari ClearPass.

      


      

        

          

            Default Vendor Aruba: UDP 5999
            
Di ClearPass, vendor type "Aruba" menggunakan port legacy 5999. Pastikan controller dikonfigurasi menerima port ini.

          

          

            Standard RFC 3576: UDP 3799
            
Aruba Central Gateways dan ArubaOS modern umumnya mendengarkan di port standar 3799.

          

        

        

          
# Cek statistik CoA di controller:

          
(MC-01) # show rfc3576 statistics

          
# Jika Bad Authenticator meningkat -> Shared Secret tidak cocok!

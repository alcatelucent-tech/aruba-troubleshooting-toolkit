AP Discovery & Join Flow: AOS 8 vs AOS 10

Tahapan booting access point hingga berhasil mendapatkan status UP dan melayani SSID.

1. Urutan Discovery Controller (Discovery Order Hierarchy)

Saat AP booting dan mendapatkan IP DHCP, AP mencari Mobility Conductor (MC) atau Local Controller dengan urutan berikut:

  1. Static Environment: Variabel NVRAM tersimpan di AP (`master=<ip>`).
  2. DHCP Option 43: Vendor specific string berisi IP Controller.
  3. ADP (Aruba Discovery Protocol):
    • Multicast: Mengirim frame ke IP 239.0.82.11.
    • Broadcast: Mengirim UDP packet ke port UDP 8211.
  4. DNS Resolution: Resolve query default: aruba-master.<domain-name-dari-dhcp>.

2. Control Plane Security (CPsec) & Port Firewall

Setelah IP Controller ditemukan, komunikasi control-plane wajib melewati enkripsi IPsec (CPsec). Jika CPsec aktif dan sertifikat/MAC AP belum disetujui (Approved), AP akan masuk status I (Inactive) atau U (Unprovisioned).

# Verifikasi IPsec SA dan Status CPsec di Mobility Conductor / Controller:

(MC-01) # show whitelist-db cpsec

1. Alur Zero Touch Provisioning (ZTP) Cloud

Pada AOS 10, tidak ada Mobility Master lokal. Seluruh AP bertindak sebagai cloud-managed device dan berkomunikasi langsung ke Aruba Central menggunakan enkripsi WebSocket/TLS.

  1. DHCP Initialization: AP wajib menerima IP, Default Gateway, DNS Server, dan resolusi NTP time yang valid.
  2. Koneksi ke Aruba Activate: AP melakukan HTTPS GET request ke activate.arubanetworks.com (Port 443).
  3. Mutual TLS via TPM Chip: AP melakukan handshake menggunakan sertifikat hardware pabrik yang tersimpan di chip TPM.
  4. Redirect ke Central Cluster: Activate merespons dengan URL cluster Central tempat tenant berada (contoh: app-ap1.central.arubanetworks.com).
  5. Image Upgrade & Config Pull: Jika AP masih menjalankan AOS 8/Instant, Central memerintahkan upgrade ke image AOS 10 dan mengunduh konfigurasi Group.

2. Titik Kegagalan Paling Sering (Common Failure Points AOS 10)

NTP Desynchronization (Clock Skew)

Jika jam AP selisih > 5 menit dari waktu UTC, handshake TLS ke Activate atau Central akan di-drop secara otomatis (Certificate Date Invalid).

Unassigned License / Group

AP sudah muncul di *GreenLake Device Inventory*, tetapi belum diberi *Foundation/Advanced License* atau belum dimasukkan ke Group AOS 10.

Egress Firewall Blocking Outbound 443

Firewall kantor/cabang memblokir HTTPS Inspection atau membatasi port outbound TCP 443 ke subnet cloud Aruba.

Stuck in Conversion Loop

AP gagal download image AOS 10 karena MTU bottleneck atau drop saat transfer image dari Cloud Repository.
